# Contributing

Thanks for helping keep this CLF-C02 study repository accurate and useful.

## What contributions are welcome

Good contributions include:
- correcting stale AWS terminology
- fixing broken official links
- updating exam-scope changes
- improving confusing explanations
- adding original practice questions that map to public task statements
- clarifying service comparisons
- improving accessibility or navigation

## Source standard

For scope-sensitive changes, please cite an official AWS source whenever possible.

Preferred order:
1. CLF-C02 Exam Guide
2. Domain task statement page
3. In-Scope / Out-of-Scope service page
4. Current AWS service documentation
5. AWS Skill Builder / Certification Prep

Community sources can support a study-strategy discussion, but should not override current AWS documentation.

## Practice-question rules

Practice questions must be:
- original
- scenario-based where useful
- clearly explained in the answer key
- aligned to public AWS documentation

Do not submit:
- exam dumps
- recalled live-exam questions
- leaked exam content
- material advertised as “real current exam questions”

## Keep exam scope clean

AWS changes quickly. A service being modern or popular does not automatically make it CLF-C02 material.

If adding newer services such as Bedrock or AgentCore:
- verify whether they are in the current CLF-C02 scope
- otherwise label them **supplemental / beyond CLF-C02**

## Keep examples generic

Do not add unnecessary personal information, employer-specific examples, private URLs, account identifiers, phone numbers, emails, or personal project names.

Prefer examples such as:
- `Project=WebApp`
- `Department=Engineering`
- `Environment=Production`

## Before opening a change

Please check:
- the official link still works
- the service name is current
- the change does not blur exam scope with broader AWS learning
- no PII or private data is included
- no `TODO` or unfinished placeholder remains

Thanks for helping learners study from current, trustworthy material.
