# AWS Skill Builder & Official Exam Prep

Use official AWS training to **diagnose gaps**, not to collect completion badges.

## Best current entry points

### AWS Certified Cloud Practitioner exam page
https://aws.amazon.com/certification/certified-cloud-practitioner/

1. Review the exam guide.
2. Take the **AWS Certification Official Practice Question Set**.
3. Take the **AWS Certification Official Pretest**.
4. Refresh weak areas.
5. Review and practice exam-style questions.
6. Take the **AWS Certification Official Practice Exam** if available in your Skill Builder access.

## AWS Cloud Practitioner Essentials

Current course entry point:
https://skillbuilder.aws/learn/94T2BEN85A/aws-cloud-practitioner-essentials/8D79F3AVR7

At the latest validation, AWS listed the course as approximately **12h45m**, Fundamental level, and updated in 2026.

### How to use it

If your exam is close:
- do **not** force yourself through every minute
- use the course to patch weak domains found by the Pretest or question set
- prioritize Security, core services, and service-use-case recognition

If you have more time:
- complete it end to end
- pair each section with the relevant notes in this repository
- finish with official question sets and the weighted mock here

## Practice rule

After every missed question, classify the reason:

- service not known
- two services confused
- shared-responsibility mistake
- pricing/support mistake
- framework/concept gap
- misread wording

Then review **only the relevant section**.

## Avoid stale bookmarks

1. Open the Cloud Practitioner certification page.

Do not conclude that a resource has disappeared merely because an old direct course URL redirects.
