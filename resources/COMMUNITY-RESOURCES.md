## Third-party practice

Well-maintained third-party practice tests can help with:
- scenario-reading speed
- eliminating plausible distractors
- identifying weak service pairs

Choose providers that explain **why** an answer is correct rather than only giving answer letters.

## Community discussion

Recent candidate discussions can help you understand common study experiences, but they must not define the curriculum.

Good use:
- study-strategy ideas
- pacing advice
- recurring areas learners find confusing

Bad use:
- memorizing recalled live questions
- assuming reported questions will appear on your exam
- treating a Reddit comment as more authoritative than AWS documentation

## Exam integrity

Do not use or contribute:
- exam dumps
- leaked live questions
- reconstructed current exams
- material marketed as “real current exam questions”

This repository uses original practice questions designed around the public AWS blueprint.
